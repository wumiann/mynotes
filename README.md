# MyNotes

自托管的个人笔记应用：富文本文案 + 密码卡片 + 少量图片，单用户设计，NAS Docker 一键部署，Web / 安卓 App / PWA 多端使用，支持离线。

- **零知识加密**：密码卡片在设备本机加密后才上传，服务器被拖库也拿不到内容
- **离线优先**：安卓 App 数据本地缓存，断网可看可改，联网自动同步
- **轻量单容器**：一个 Docker 容器 + 一个数据卷，备份 = 拷贝目录

## 功能一览

- **富文本笔记**：标题/加粗/列表/引用/代码块/链接/图片（粘贴、拖入、点击上传均可）
- **密码卡片**：名称/网址/多套账号密码/备注；AES-256-GCM 本机加密存储；支持明文与加密两种模式，逐条可切换
- **组织**：分组树 + 标签，选中分组新建自动归组，桌面支持拖拽入组
- **搜索**：标题与内容全文搜索（中文友好），明文卡片也可搜索
- **版本历史**：每条笔记保留最近 5 个版本，可查看 diff 并一键恢复
- **回收站**：软删除、恢复、彻底删除、自动清理（可配置）
- **备份**：一键导出 zip / 上传还原；服务端每日自动备份（保留 7 份）
- **导入**：支持群晖 DS Note 的 `.nsx` 导出文件迁移
- **多端同步**：60 秒轮询 + 聚焦/改动触发，冲突时后写胜出且被覆盖版本进历史
- **界面**：深浅色主题、应用内对话框、移动端自适应

## 快速开始（Docker 部署到 NAS / 服务器）

### 方式一：加载预构建镜像（推荐，无需现场构建）

从 [Releases](https://github.com/wumiann/mynotes/releases) 下载对应架构的镜像 tar（x86 选 amd64、ARM 选 arm64），传到 NAS 后：

```bash
docker load -i mynotes-docker-arm64.tar
```

项目内的 `docker-compose.yml` 默认使用加载的镜像（标签随版本变化，当前 v0.2.14 为 `mynotes:0.2.14-arm64` / `mynotes:0.2.14-amd64`，与 docker load 后的标签一致即可），直接：

```bash
docker compose up -d
```

### 方式二：从源码构建

```bash
git clone https://github.com/<你的用户名>/mynotes.git
cd mynotes
docker compose -f docker-compose.build.yml up -d --build
```

两种方式部署后服务都会监听两个端口：

- **HTTPS 8443**（自签名证书，服务首次启动自动生成）—— **推荐日常使用**，加密功能完整可用
- **HTTP 8322** —— 兼容端口，适合本机浏览器（localhost）或不需要加密卡片的场景

> **为什么必须 HTTPS？** 浏览器的安全规则只在 HTTPS 页面提供加密能力（Web Crypto）。局域网 HTTP 访问时，登录派生与密码卡片加密会在浏览器侧被禁用——这是所有依赖 Web Crypto 的应用的共同限制，不是本应用的 bug。HTTPS 使用自签名证书，首次访问浏览器会提示"不是私密连接"，点「高级 → 继续访问」接受一次即可。

部署后访问 `https://<NAS-IP>:8443`（推荐）或 `http://<NAS-IP>:8322`，首次打开创建账号即可使用。

- 数据全部保存在 `./data` 目录（SQLite + 附件），**备份 = 拷贝整个目录**
- 服务启动 30 秒后会在 `data/backups/` 自动生成每日备份，保留 7 份
- 换端口：修改 compose 文件的端口映射即可
- 安卓 App 服务器地址同样填 `https://<NAS-IP>:8443`（App 已放行自签名证书）

## 使用说明

### 账号与加密

- 首次访问创建账号；密码既用于登录，也在**本机**派生出卡片加密密钥——服务器永远接触不到密钥和卡片明文
- **主密码丢失无法找回**，加密卡片将永久无法解密，请务必牢记
- 密码卡片默认加密存储（可在编辑器内逐条切换明文/加密）；解锁状态图标（侧栏左下角 🔓/🔒）表示本机是否持有解密密钥

### Web 使用

浏览器直接访问 `http://<NAS-IP>:8322`。支持 PWA：浏览器菜单 → 添加到主屏幕，可离线缓存静态资源。

### 安卓 App（Flutter 原生，本地优先）

从 [Releases](https://github.com/wumiann/mynotes/releases) 下载 `MyNotes-release.apk` 安装。**打开即用，无需先配置服务器**——数据仅保存在本机，离线完整可用：

- **配置同步**（可选）：设置 → 同步 → 配置向导（地址探活 → 登录 → 首次同步策略）。策略三选一：
  - **合并（推荐）**：本地新增上传、服务器数据下载，同一条两端都改过时保留较新版本（被覆盖版本进 Web 版历史）
  - 仅上传（本地为准）/ 仅下载（服务器为准，会清空本机未同步数据，有二次确认）
- **NAS 无公网 IP 也能用**：连不上服务器时照常读写，变更存在本地队列；回到局域网 / VPN 后自动补推合并（60 秒周期 + 打开应用时 + 手动点同步徽标）
- 顶部按钮：新建笔记 / 新建卡片（图标随解锁状态变化）；加密卡片需配置同步并登录后使用
- 更换服务器 / 断开同步（本机数据保留）：设置 → 同步

### 备份与还原

设置 → 数据：

- **备份导出**：下载 zip（数据库 + 图片），建议定期保存到其他位置
- **导入还原**：上传备份 zip 覆盖当前数据（完成后服务自动重启）
- **DS Note 导入**：上传群晖 Note Station 的 `.nsx` 导出文件迁移旧笔记

### 密码卡片加密说明

- **加密卡**：内容（账号/密码/备注）AES-256-GCM 加密存储，标题明文可搜索；未解锁时显示掩码
- **明文卡**：全部明文，可被服务端搜索，打开无需密码
- 解密密钥仅存于本机：浏览器会话内 / App 本地存储；「设置 → 安全」可切换锁定策略，或随时手动锁定
- 修改主密码会自动用新密码重加密全部加密卡片

## 自动保存与同步

### 保存时机（Web 与 App 一致）

- 编辑停止 **30 秒**后自动保存（有实际改动才保存，不会为无意义的修改留版本）
- **立即保存**：切换笔记、返回列表、关闭编辑器、Ctrl/Cmd+S，或点击「未保存」状态文字
- 每次有效保存自动留一个版本快照（保留最近 5 个），编辑器底栏「历史」可查看每次改动的 diff 并一键恢复

### 多端同步

**Web 浏览器**：数据保存在服务器。打开的笔记若被其他端修改、且本地没有未保存的改动，会在约 60 秒内自动刷新（切回标签页/聚焦窗口时立即检查）。

**安卓 App（离线本地优先）**：

- 未配置服务器时即为纯本地笔记，数据仅存本机；配置同步后首次按所选策略合并
- 此后断网也能浏览/编辑；联网时自动同步：有改动约 2 秒后推送、每 60 秒合并拉取、切回前台立即同步
- 长期离线产生的变更持久化在本地队列，恢复网络后自动补推合并，不会静默丢失
- 列表顶部徽标显示同步状态：☁ 未配置同步 / ✓ 已同步 / ⏳N 条待同步 / ⛔ 离线，点击可手动同步
- 需要联网的操作（离线时会有明确提示）：分组/标签管理、备份还原、DS Note 导入、修改主密码、上传图片

**冲突处理**：两端同时修改同一条笔记时，后保存的一方胜出；被覆盖的内容会自动进入该笔记的版本历史，可在「历史」中查看 diff 找回，不会静默丢失。

## 从源码构建

```bash
# 本地运行（开发）
pnpm install
pnpm dev:server   # http://127.0.0.1:8322
pnpm dev:web      # 前端热更新 http://127.0.0.1:5173

# 构建 + 冒烟测试
pnpm build && pnpm smoke

# 安卓 APK（Flutter 版，需 Flutter SDK 与 Android SDK）
cd flutter_app
flutter build apk --release
# 产物：flutter_app/build/app/outputs/flutter-apk/app-release.apk
```

## 技术栈

- **服务端**：Fastify + Node 内置 `node:sqlite`（无原生编译依赖）+ fflate
- **前端**：Vue 3 + Vite + Tiptap
- **安卓**：Flutter（sqflite 本地库 + 变更队列同步引擎，离线本地优先；编辑器为 AppFlowy，与 Web 端 Tiptap JSON 双向无损转换）
- **安全**：零知识认证（PBKDF2 600k 派生）、卡片 AES-256-GCM 加密、登录限速、会话管理

## 安全说明

- 面向内网设计：请勿将端口直接暴露到公网；外网访问建议 Tailscale 或带认证的反向代理
- 卡片内容加密后才上传，服务器仅存密文与明文标题
- 登录失败 5 次锁定 15 分钟；可在设置中登出其他设备
- 自动备份与手动导出的 zip 内含数据库与图片，请妥善保管
