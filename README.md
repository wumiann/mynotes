# MyNotes

自托管的个人笔记应用：富文本文案 + 密码卡片 + 少量图片，单用户设计，NAS Docker 一键部署，Web / 安卓 App / PWA 多端使用，支持离线。

- **零知识加密**：密码卡片在设备本机加密后才上传，服务器被拖库也拿不到内容
- **离线优先**：安卓 App 数据本地缓存，断网可看可改，联网自动同步
- **轻量单容器**：一个 Docker 容器 + 一个数据卷，备份 = 拷贝目录

## 功能一览

- **富文本笔记**：标题/加粗/列表/引用/代码块/链接/图片（粘贴、拖入、点击上传均可）
- **密码卡片**：名称/网址/多套账号密码/备注；AES-256-GCM 本机加密存储；支持明文与加密两种模式，逐条可切换
- **组织**：分组树 + 标签，选中分组新建自动归组，桌面支持拖拽入组
- **搜索**：标题与内容全文搜索（中文友好），明文卡片也可搜索
- **版本历史**：每条笔记保留最近 5 个版本，可查看 diff 并一键恢复
- **回收站**：软删除、恢复、彻底删除、自动清理（可配置）
- **备份**：一键导出 zip / 上传还原；服务端每日自动备份（保留 7 份）
- **导入**：支持群晖 DS Note 的 `.nsx` 导出文件迁移
- **多端同步**：60 秒轮询 + 聚焦/改动触发，冲突时后写胜出且被覆盖版本进历史
- **界面**：深浅色主题、应用内对话框、移动端自适应

## 快速开始（Docker 部署到 NAS / 服务器）

```bash
git clone https://github.com/<你的用户名>/mynotes.git
cd mynotes
docker compose up -d --build
```

访问 `http://<NAS-IP>:8322`，首次打开创建账号即可使用。

- 数据全部保存在 `./data` 目录（SQLite + 附件），**备份 = 拷贝整个目录**
- 服务启动 30 秒后会在 `data/backups/` 自动生成每日备份，保留 7 份
- 换端口：修改 `docker-compose.yml` 的端口映射即可

## 使用说明

### 账号与加密

- 首次访问创建账号；密码既用于登录，也在**本机**派生出卡片加密密钥——服务器永远接触不到密钥和卡片明文
- **主密码丢失无法找回**，加密卡片将永久无法解密，请务必牢记
- 密码卡片默认加密存储（可在编辑器内逐条切换明文/加密）；解锁状态图标（侧栏左下角 🔓/🔒）表示本机是否持有解密密钥

### Web 使用

浏览器直接访问 `http://<NAS-IP>:8322`。支持 PWA：浏览器菜单 → 添加到主屏幕，可离线缓存静态资源。

### 安卓 App

从 [Releases](https://github.com/wumiann/mynotes/releases) 下载 `MyNotes-debug.apk` 安装，首次打开输入服务器地址 + 账号密码：

- **离线可用**：数据本地缓存，断网可看可改，联网自动同步
- 顶部按钮：🔒 新建加密卡片 / 🔓 新建明文卡片 / ＋ 新建笔记；侧栏底部图标显示解锁状态，点击可锁定/解锁
- 换服务器地址：在侧栏点锁定图标旁的设置，或登出后重新输入

### 备份与还原

设置 → 数据：

- **备份导出**：下载 zip（数据库 + 图片），建议定期保存到其他位置
- **导入还原**：上传备份 zip 覆盖当前数据（完成后服务自动重启）
- **DS Note 导入**：上传群晖 Note Station 的 `.nsx` 导出文件迁移旧笔记

### 密码卡片加密说明

- **加密卡**：内容（账号/密码/备注）AES-256-GCM 加密存储，标题明文可搜索；未解锁时显示掩码
- **明文卡**：全部明文，可被服务端搜索，打开无需密码
- 解密密钥仅存于本机：浏览器会话内 / App 本地存储；「设置 → 安全」可切换锁定策略，或随时手动锁定
- 修改主密码会自动用新密码重加密全部加密卡片

## 从源码构建

```bash
# 本地运行（开发）
pnpm install
pnpm dev:server   # http://127.0.0.1:8322
pnpm dev:web      # 前端热更新 http://127.0.0.1:5173

# 构建 + 冒烟测试
pnpm build && pnpm smoke

# 安卓 APK（需 JDK 17–21 与 Android SDK；镜像已内置）
pnpm build:app
cd android && gradlew.bat assembleDebug
# 产物：android/app/build/outputs/apk/debug/app-debug.apk
```

## 技术栈

- **服务端**：Fastify + Node 内置 `node:sqlite`（无原生编译依赖）+ fflate
- **前端**：Vue 3 + Vite + Tiptap
- **安卓**：Capacitor 7（本地打包 + IndexedDB 离线缓存 + 同步引擎）
- **安全**：零知识认证（PBKDF2 600k 派生）、卡片 AES-256-GCM 加密、登录限速、会话管理

## 安全说明

- 面向内网设计：请勿将端口直接暴露到公网；外网访问建议 Tailscale 或带认证的反向代理
- 卡片内容加密后才上传，服务器仅存密文与明文标题
- 登录失败 5 次锁定 15 分钟；可在设置中登出其他设备
- 自动备份与手动导出的 zip 内含数据库与图片，请妥善保管
