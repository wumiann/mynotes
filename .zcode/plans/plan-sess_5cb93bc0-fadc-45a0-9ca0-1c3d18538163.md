## 本地优先改造计划：独立使用 + 可选同步 + 合并策略

**核心认知**（探索结论）：数据层 data.dart 本来就完全本地优先（写本地+入队无登录守卫），挡住独立使用的只是入口路由；现有同步是"先推后全量替换"，对本地数据天然等效合并，但有 3 条静默丢数据的路径要堵。**服务器与 Web 端零改动。**

### 一、入口改造：进 App 即可用
1. main.dart：删掉 BootstrapPage 强制路由——**永远直接进 HomePage**。已配置（地址+token）→ bootSync 登录态；未配置 → 本地模式（不启动 60s 同步循环，避免空转）
2. 本地模式标识与引导：
   - 列表空态改文案：「数据仅保存在本机，配置同步后可与 Web 版互通」+「去配置」按钮
   - AppBar 同步徽标：本地模式显示「未配置同步」图标（cloud_off），点击进设置
   - 加密卡：独立模式下新建加密卡按钮/抽屉解锁图标 → 点击提示「加密卡片需登录服务器后使用」（置灰不可用）；普通卡片正常

### 二、设置新增「同步」区块 + 配置向导
1. settings_page 顶部新增同步区：未配置显示「未配置 · 去配置」；已配置显示地址/账号/上次同步/待同步 N 条 + 操作：立即同步、更换服务器、断开同步（=登出，保留本地数据）。账号区的「登出其他设备」本地模式隐藏
2. 新建 SyncSetupPage 向导（原 BootstrapPage 改造纳入）：地址输入（自动补 :8322 + 探活）→ 登录/注册（复用 LoginPage）→ **首次同步策略选择**：
   - **合并**（默认推荐）：本地新数据上传 + 服务器数据下载，同一条两端都改过则新者胜（被覆盖版本进服务器版本历史兜底）
   - 仅上传（本地为准）：本地全量推上去覆盖服务器 —— 红字警告
   - 仅下载（服务器为准）：清空本地未同步数据后全量拉取 —— 红字警告
   - 执行后展示结果（上传 X / 下载 Y / 冲突 Z）→ 完成进列表

### 三、同步引擎（核心改造，sync.dart）
1. **新增 mergePull 三路合并**（常规同步与"合并"策略都用它，替代现在无脑的全量替换）：
   - 服务器独有 → 插入本地
   - 本地独有 → 跳过（其推送由 queue 已有的 op 负责；queue 里没有的视为服务器端已删，不复活）
   - 双方都有 → updatedAt 新者胜：服务器新 → 覆盖本地行并清掉该笔记的过期队列 op；本地新 → 入队推送（走现有 409 本地胜出路径）
   - groups：维持 push 后服务器全量替换（Flutter 端无新建分组入口，安全）
2. **顺序保证不变**：先 push 队列，再 pull 合并；push 失败跳过 pull（现状已对）
3. **堵死三条静默丢数据路径**：create 遇 400/409、update 409 重试再 409 → 改为**保留队列 op 并中止本轮**（不再静默丢弃后被全量拉取抹掉）；仅 update/delete 遇 404（服务器已删）才安全丢弃
4. _pullFull（破坏性全量替换）仅「仅下载」策略使用
5. 断线恢复：保留 60s 定时 + 回前台触发 + 下拉刷新 + 设置「立即同步」；不引入网络监听依赖（60s 粒度 + 徽标状态已覆盖你的场景，以后要秒级检测再加 connectivity_plus）
6. 本地模式产生的数据：全部在 queue 里排队（现有机制天然支持），配置服务器后首次同步自动补推+合并——正是你要的"恢复网络后把期间的账一起算"

### 四、localdb 小改
新增：按笔记查待推送 op（防重复入队）、按笔记清队列 op（合并时清过期）、本地原始全量读（合并用）。kv 表保持不用（策略是一次性参数，不持久化）。

### 五、验证
1. flutter test：mergePull 三路合并单测（本地独有/服务器独有/双端修改/冲突新者胜，真实 fixture）
2. 模拟器端到端：清数据 → 独立建笔记/卡片/待办（无服务器）→ 配置服务器选「合并」→ 验证本地数据上推+Web 端数据下拉 → 断网编辑 → 恢复网络 → 自动补推落库 → Web 端改同一条 → 新者胜合并
3. 登出后数据保留可看、重新登录后继续同步

### 明确不做
不动服务器与 Web 端；不做字段级/段落级合并（笔记级新者胜+服务器版本历史兜底）；不引入 connectivity_plus；独立模式不支持加密卡（你已确认）。

改动范围：sync.dart（核心）、localdb.dart、main.dart、home_page.dart、note_list_page.dart、settings_page.dart、新 SyncSetupPage、BootstrapPage 改造。完成后模拟器全量回归 + 截图 + 提交推送。
